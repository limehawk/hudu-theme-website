# Contributing

This site renders themes from the [limehawk/hudu-themes](https://github.com/limehawk/hudu-themes) repo — to add or fix a theme, contribute there (see its README). Once a theme lands on that repo's `main`, rebuilding this site picks it up:

```bash
HUDU_THEMES_DIR=../hudu-themes bun run build
```

Site bugs and design issues: open an issue or PR here.
